# JARVIS ULTRON Android

This is a clean Android Studio project containing the JARVIS/ULTRON HUD and a user-enabled Android Accessibility Service.

## What is included

- ULTRON 3D HUD
- Voice recognition
- Text-to-speech-ready brain
- Groq API brain integration
- Android Accessibility Service
- Home / Back / Recents / Notifications / Quick Settings actions
- Basic app launching
- Text-based accessibility clicking
- Android Studio Gradle project
- GitHub Actions APK build workflow

## Setup

1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build the app.
4. Install it on your phone.
5. Grant microphone permission.
6. Open Android Accessibility settings and enable JARVIS.
7. Add your own Groq API key if you want the AI brain.

## Security boundary

JARVIS does not bypass the Android lock screen, secretly record the microphone, or silently defeat Android security controls. Phone-control features operate through normal Android permissions and the user-enabled Accessibility Service.
